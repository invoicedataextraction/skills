# Invoice Data Extraction skills

Skills for AI agents that use [Invoice Data Extraction](https://invoicedataextraction.com): invoices, receipts, bank statements and other financial documents turned into structured rows and spreadsheets through its API.

- `invoice-data-extraction/SKILL.md`: how to run an extraction end to end, answer the questions it asks, and read the rows. The guide it condenses is https://invoicedataextraction.com/docs/agents.

The copy kept current is served from the domain and indexed at https://invoicedataextraction.com/.well-known/agent-skills/index.json; this repository mirrors it. Install from the domain with `npx skills add https://invoicedataextraction.com`, or from this repository with a harness that installs skills from GitHub.

Docs for agents: https://invoicedataextraction.com/llms.txt. Licensed under the MIT License.
